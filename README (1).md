# My Week Planner

A personal weekly agenda that runs in the browser. It's a single HTML file with no install and no server.

## Features
- Week view, Monday to Sunday, 06:00 to midnight, with a "now" line
- Click an empty slot or use **+ Add task** to add a task
- Drag a task to move it, or drag its top or bottom edge to resize it
- Drag a category from the top bar onto a day to create a 2-hour task
- Custom categories with your own names and colours (**✎ Customise**)
- Ctrl/Cmd+click to select several tasks and rename or recolour them together
- Repeat tasks weekly and tick them off when done
- Undo button (and Ctrl/Cmd+Z)
- Backup and restore your tasks as text

## How to use
Open `index.html` in any modern browser (Chrome, Edge, Firefox, Safari).

Tasks are saved in your browser's local storage, so they stay on the computer and browser you use. They are **not** stored in this repository. Use **Backup** to copy them somewhere safe.
